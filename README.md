# RaceDayDB Project

## Purpose
This project is a race day management system database for storing roles, users, events, categories, enrolments, and results.

## Functionality
- SQL Server database with tables for race management
- Sample data for testing
- ERD and API endpoint documentation included

## Setup Instructions
1. Clone the repository
2. Open `RaceDayDB.sql` in SQL Server Management Studio
3. Execute the script to create and populate the database
4. Refer to `/docs` for ERD and API endpoint table
